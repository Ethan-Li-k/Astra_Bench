# 独立 Reviewer 决策记录

## D1：开始单次有界读取
- 当前问题：确认父目录已落地实现、成功判据和 actor 信息边界有哪些可核验事实。
- 总目标：形成有路径、行号、哈希的独立工程就绪性审查；只写 reviewer/，一次读审后退出。
- 不可重犯的错误：不读 auth.json/api.json 或凭据；不干预 supervisor；不启动模型或仿真；不改共享 skill；不把 R018 旧成绩计入新任务；不将推测或未落地实现标为 PASS；宿主真值不流入 actor 经验。
- 决策：先读指定任务、交接、来源快照和既有角色报告，再审查冻结副本及父目录新增源码。

## D2：冻结本次审查输入
- 当前问题：父工程仍在写入，审查必须明确对应版本，不能把后续修改混入结论。
- 总目标：对当前已存在文件形成可复核的单次静态审查和精确反例。
- 不可重犯的错误：不轮询工程、不运行仿真；不把 preflight 或旧桌面成绩计为地面任务成功；不向 actor 传播宿主真值。
- 决策：仅复制明确允许的源码、文档和 preflight JSON 至 reviewer/evidence，记录读取时哈希；报告只针对这些副本。

## D3：用无仿真的逻辑反例验证关键疑点
- 当前问题：已落地 PhaseAudit 可能只检查阶段标志的次序，未检查实际抓取起始事件；模型封印字段与 actor 文件权限也需要界定。
- 总目标：将可复现缺陷与尚待物理验证的假设分开，给工程最小修复和回归用例。
- 不可重犯的错误：合成轨迹不是物理成功或示范；不导入/实例化仿真，不启动模型；不将本报告或宿主样本给 actor。
- 决策：从冻结源码 AST 仅提取 PhaseAudit、CRITERIA、model_digest，运行原有纯逻辑测试及少量独立反例；接线和权限结论限定为静态代码证据。

## D4：发布限于已捕获版本的审查结论并退出
- 当前问题：源码保留及若干防误计门槛已核验，但阶段次序/桌侧接触反例被误判，完整性字段和 actor 文件隔离仍有缺口。
- 总目标：让工程收到可复现、分级、有来源的修复/测试清单，下一次只在新代码或新回合事件触发时复审。
- 不可重犯的错误：不把纯逻辑 PASS 当物理成功；不将上游 --skip-harness 误说成完全没有先行 validator；不把还未接线的任务 runner、技能或隔离机制当已验证。
- 决策：结论为正式记分尚未就绪；保留冻结源码、原文核验、11 项原测试及独立反例结果；只输出工程报告，不发消息给 supervisor，不轮询后续变化。
