# 单回合工作笔记模板

- 原始任务指令：由 host 提供。
- 当前回合/最新观测编号及曝光时间：未开始。
- 当前正在尝试的子目标：未开始。
- 已由视觉确认完成：无。
- 剩余目标与前提：待观察。
- 几何估计：值、坐标系、来源观测、误差或不确定性。
- 最近动作：请求编号、观测锚点、参考起点、固定目标、实际执行回执。
- 实际变化与预期差异：未观察。
- 失败/撤回：可观察现象、证据编号、下一次改变什么；不推测成既定根因。
- 待验证事项：抓取、接触或到位不确定时明确保留。

此笔记不包含物体真值、奖励查询、其他回合答案或私有推理过程。
历史开发结论和系统辨识记录保留在开发区，不直接注入此模板。
