# 用户最新更正与明确回答

原话：写入全局约束，六项测试是训练集，测试集是你挑选的相关任务，训练集成功才能进入测试集，根据测试集测试结果再找新的训练集训练，60%我是指抓苹果任务抓取的成功率大于60%就可以尝试，继续优化策略，加快速度，节省不必要的步骤。

追问确认：某一项训练成功，就测试与它相关的任务，其余五项继续并行训练。用户回答：按任务族解锁（推荐，速度更快）。

生效：指定六项为训练；相关任务为测试。按对应任务族原生成功证据解锁，不等六项全部成功。60%仅为抓苹果抓取尝试的充分条件，严格>60%，不是所有任务的估计概率门槛，也不要求额外统计证明才允许模型行动。测试结果指导下一训练轮；测试期间冻结，回合后学到的案例标明已暴露。历史结果不改写，原50次有效尝试总目标保留但20训练+30六项测试旧分配撤销，不恢复60×5。
