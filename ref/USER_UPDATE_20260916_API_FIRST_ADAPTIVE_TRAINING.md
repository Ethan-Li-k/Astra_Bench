## DAgger 思想的准确使用

DAgger 的核心是收集当前策略实际访问状态上的专家纠正并聚合数据，再更新策略；“失败多就多试”本身是难例优先调度。优先保存自主 rollout 的偏离/恢复状态，附可审计纠正标签，随后在独立重置验证。没有可靠专家标签或真实参数优化时，不宣称完成 DAgger 训练，也不把模型自评作为真值。

## 低优先级独立三维监督实验

- 用户已授权独立实验窗口。放在独立目录/候选/网页页签，先用已有数据做最小离线实验，不占主六项物理槽位，不启动大规模训练。主线仍优先。
- 训练侧允许深度、相机位姿、物体几何、末端轨迹及仿真自动标签；标注 supervised/privileged training 来源，不混称无辅助 Direct。仅训练导出器和离线教师可读，RGB student 和正式接口不得收到特权字段或透过文件路径/工具访问它们。
- 对照：RGB 基线；RGB 输入＋训练侧3D监督/技能提炼；使用3D输入的教师上界另列。按 episode/reset/物体/相机布局划分留出，禁止相邻帧跨训练测试泄漏。报告三维坐标误差、旋转误差、轨迹可行性及少量同条件成功率，不只报告训练误差。
- 先声明预测坐标系、单位、旋转表示、相机标定和机器人状态是否可见。严格RGB不能偷偷加入深度、动态相机位姿、物体真值或proprio；若任务需要这些，另列 RGB＋固定标定/本体状态 对照。单目尺度/遮挡歧义应输出不确定性，不能靠评测标签补全。
- 固定 Astra/xhigh 的 prompt/skill 更新不是模型权重训练。先做数据可用性/标签几何一致性/最小 RGB 提炼实验；实际梯度训练须先确认当前模型与接口可用，不能自动换模型、宣称学到几何先验或声称已验证。
- 正式榜单接口需核实官方合同；此想法目前是待验证的独立对照，不静默改变正在运行的主线观测合同。
