# 用户抓盒子与API最新指示

原话1：注意抓盒子任务有两个要点1.单手抓取盒子，一把抓住，否则碰倒在桌上很难抓起 2.盒子掉落地面立即停止，如果盒子位置靠近桌子边沿，盒子落地要写入经验明白下次如何改进

原话2：开始使用API，另外先蹲下让双手到合适位置再抓取是更稳的选择

实施语义：先蹲低，使双手达到合适作业高度，再单手对准包围盒子后闭合，另一手避让；目标是稳妥一次抓住，不能误设只能尝试一次的额外失败条件。双手就位不等于双手夹盒；抓稳后的交接/搬运仍按任务指令。桌面倒伏与地面掉落分开；目标确认落地立即停止当前尝试，不再地面捡拾或继续无意义推理。落地是用户明确的任务止损失败，不伪装API/工程中断；原生成功字段仍遵守原生任务。保存掉落前后RGB、原动作和ACK、桌边关系、失败原因与下次具体改法，所选原文供下一回合实际读取。看不见目标不等于落地。
