# 停止测试、审核训练能力、抓盒倒伏止损（用户原话）

抓取盒子的任务都没有训练成功，进入训练集抓取是不正确的，完成训练集的审核，明确任务能力再进行测试，另外盒子掉落地面或倒在桌面记入失败经验，下次应该避免再碰倒，停止测试，重新开始

执行边界：先暂停测试派发并在完整推理/动作回执边界收口当前实验，再审核训练集的真实原生成功、阶段进展和工程中断。既有训练/测试角色和旧结果保留，不把接口检查或局部到位当作抓取能力。审核前不解锁相关测试，审核后只按明确能力范围重新安排基础训练与测试。

盒子确认落地，或从原先稳定支承姿态被碰倒在桌面，结束本次抓取尝试并单列失败经验；不继续地面/桌面倒伏后的拾取来掩盖第一次失败。原生结果字段如实保留，额外记录用户止损原因。初始配置本来平躺与本次动作碰倒不同；遮挡或轻微倾斜不能直接当作已倒伏。保存原始支承姿态、碰倒前后RGB、动作/ACK、手掌或指尖扫过的位置、桌沿关系，以及下一回合需要改变的接近方向、高度或姿态。观察事实与原因假设分别记录。

继续优先已授权 API，固定 gpt-6-astra/xhigh。蹲低到合适作业高度仍是优先方法，不强制弯腰或固定蹲姿。完整等待已发推理，未知动作不重放。运行回合不热改共享 skill；新回合实际加载修改后的指导并保留来源。
