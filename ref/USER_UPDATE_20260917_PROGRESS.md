# 用户追加：因果进度监督

本条覆盖旧“学习回合累计时间无限、finish_attempt 必须继续”规则。API 停用及禁止主账号继续有效。

Mobile P&P 必须按获取物体、双手独立稳定保持、持物移动、支持后放下松手的顺序执行。掉物撤销搬运资格，返回抓取。禁止把搬运回合变成空手步态研究。480 秒是用户预期完成时间和复核点，不是 Astra 推理时限；实际持物并持续接近目标的慢回合可以继续。没有掌握前置步骤或长时间物理停滞时停止学习回合，保留视频和失败证据，下一目标聚焦缺失前置技能。

首版具体阈值保存在 rsi/task_progress.py 的 MOBILE_PROGRESS；它们是待物理验证的工程初值，不是假称已验证的最优参数。只统计模型动作期间的仿真时间，不消耗推理等待时间。

这版训练监督使用宿主仿真接触/相对运动核验双手持物；原始物体位置、接触、距离不进入 actor 输入。actor 得到阶段准入/停止反馈，必须标为 simulator_supervised_progress_learning，不计纯 RGB 正式测评，不沿用为冻结 Direct 稳定性成绩。其他任务不能直接套用 Mobile 的双手要求；复用 progress skill 的时序与证据原则，按任务另设退出条件。

历史复盘：Mobile episode-0002 动作 269–280 有暂时夹起/静止保持迹象，281–282 迈步后掉物，284 以后继续大量空手步态研究。615 个动作最终因失稳停止，2149.78 秒任务物理时间。旧回合不倒签新规则，不冒称已受新监督。
